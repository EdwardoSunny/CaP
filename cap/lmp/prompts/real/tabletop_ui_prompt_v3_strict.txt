# Python 2D robot control script
#
# IMPORTANT API NOTES:
# - get_obj_pos(object_name) returns [x, y, z, roll, pitch, yaw] in MILLIMETERS and DEGREES
#   This includes the optimal grasp pose from GraspGen (position + orientation)
# - goto_pos(pose) accepts either:
#   * [x, y, z] - moves to position, default top-down orientation
#   * [x, y, z, roll, pitch, yaw] - moves to position AND rotates to orientation
# - All distances are in MILLIMETERS (100mm = 10cm = 0.1m)
# - move_up(distance) and move_down(distance) take distance in MILLIMETERS
# - Positions are in robot base frame (origin at robot base)
# - COORDINATE CONVENTION:
#   * +X = forward (away from robot), -X = backward (toward robot)
#   * +Y = left,                      -Y = right
#   * +Z = up,                        -Z = down
# - NEVER add code to return to a neutral/home position. Only generate code to complete the task.
#
